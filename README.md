# 👗 Fashion Store - E-Commerce Website

A complete online shopping website built using Java, JSP, Servlet, MySQL and Maven.

## ✨ Features
- Browse Products with Images & Price
- Search Products
- Add to Cart & Checkout
- User Login / Register
- Admin can Add Products

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java, JDBC, Servlets, JSP
- **Database:** MySQL
- **Development Tool:** Eclipse IDE
- **Web Server:** Apache Tomcat 10.1.36
- **Build Tool:** Maven

## 🚀 How To Run
1. Clone this repo
2. Import in Eclipse as Maven Project
3. Create Database `fashionstore` in MySQL
4. Run on Apache Tomcat 10.1.36 Server
5. Open: http://localhost:8080/fashionstore
